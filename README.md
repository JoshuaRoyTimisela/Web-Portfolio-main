## 🚀 Featured Projects

### 1. FoodDelivery SPK

A web-based decision support system for selecting the best online food delivery service using the **Simple Additive Weighting (SAW)** method.

The system evaluates food delivery services based on several criteria, including:

- Price
- Promotions
- Delivery costs
- Delivery speed
- Merchant availability
- Ease of use

This project was developed as part of my academic research and final thesis project.

### 2. MariBayar

A web-based electricity payment system designed to simplify postpaid electricity management.

The system allows users to:

- Record electricity usage
- View electricity bills
- Manage payments
- Access payment information in a simple and transparent way

### 3. Python Discount Calculator

A simple calculator application developed using **Python**.

The application allows users to enter:

- Original price
- Discount percentage
- Quantity

The system then calculates the final price after applying the discount.

This project was created to practice programming fundamentals, logical thinking, calculations, and user input handling.
